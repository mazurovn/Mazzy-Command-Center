# Mazzy Command Center

[English](README.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [中文](README.zh.md) · **日本語** · [한국어](README.ko.md)

**[Pi](https://www.npmjs.com/package/@earendil-works/pi-coding-agent) コーディングエージェント向けの、親が証明するローカルのエージェント・オーケストレーター兼コマンドセンター。**

_作者：**Mazurov N.N.** — https://github.com/mazurovn · プロプライエタリ／ソース公開
（書面による許可なく改変・再配布は不可 — [LICENSE](LICENSE) を参照）。_

Mazzy Command Center はプロジェクトローカルな Pi 拡張で、Pi セッションを永続的で監査
可能なエージェント作業のコマンドセンターに変えます：タスクトラッカー、オーケストレー
ションの意思決定面、レビュー／証拠の台帳、そして認証済みのローカル Web ダッシュボード
—— すべてを単一の組み込み SQLite コントロールプレーン上で提供します。

> **ステータス：認証済みのローカルパイロット。** 1 台のマシン、1 人の信頼できるユーザー、
> プロジェクトローカルな永続化、プロセスレベルの親／子境界。これは**まだ**マルチユーザー、
> マルチテナント、リモート製品ではありません。[セキュリティと制限](#セキュリティと制限)
> を参照してください。

## 何をするか

Mazzy は**コントロールプレーン**であり、2 つ目の実行ランタイムではありません。作業を
記録し統制します。実際の子プロセス実行は `pi-subagents` に委譲されます。親の Pi
セッションがコントロールプレーンへの唯一の書き手であり、子エージェントは状態を直接
変更せず、親が観測した結果を証明します。

- **永続タスクトラッカー** —— エピック／機能／タスク／バグを、バージョン管理された
  ライフサイクル（`DRAFT → BACKLOG → READY → CLAIMED → RUNNING → REVIEW → DONE`、
  加えて `BLOCKED / FAILED / CANCELLED`）で管理。各更新は楽観的並行性チェックを行います。
- **親が証明するオーケストレーション** —— 親はタスクが実行中だと主張する前に、*観測
  した*子実行をタスクに束ねます。`DONE` にはコメントではなく独立した PASS 証拠が必要です。
- **認証済みローカルダッシュボード** —— `localhost` 上の自己完結型 Web UI。ケイパビリ
  ティトークン、SSE によるライブ更新、カンバンボード、タスク議論ドロワーを備えます。
- **SDD/ADR グラフ** —— 仕様条項（ADR/INV/FR）、コードコンポーネント、バックログ項目を
  1 つのフィルタ可能な連結グラフに結びつけるブラウザ内可視化。
- **安全なスキャフォールディング** —— `mazzy-init` は移植可能なプロジェクトテンプレート
  を、デフォルトのドライラン、保護された `--force`、`--rollback` とともに書き込みます。

## アーキテクチャ概観

```
人間 ── Pi コマンド / 認証済み localhost ブラウザ ──┐
                                                    v
Pi 親 + 拡張 API ── Mazzy Command Center ── SQLite コントロールプレーン
                  │       │        │
                  │       ├─ 議論 / 証拠 / レポート
                  │       └─ 証明付き制御ブリッジ
                  v
            pi-subagents（唯一の子ランタイム）
```

**中核原則（不変条件）：**

- **単一の実行ランタイム** —— 子は `pi-subagents` が実行します。Mazzy は子作業を生成、
  スケジュール、再試行、終了させません。*意思決定*の権限を持ち、*実行*の権限は持ちません。
- **親のみが書き込む** —— コントロールプレーンの変更には対話的な親が必要で、継承された
  子プロセスは拒否されます。
- **ホストパスは API を越えない** —— localhost を出るのは不透明な id、列挙値、相対参照
  のみです。
- **コメントは決して証拠ではない** —— 権威ある PASS/FAIL チャネルはレビュアー／検証者の
  証拠です。
- **すべての `git` 呼び出しは堅牢化** —— リポジトリの設定／フックや継承された環境は実行に
  影響を与えられません。

## ツールとコマンド

**親専用ツール**（LLM から見える面）：

| ツール | 目的 |
|---|---|
| `mazzy_task` | 永続タスクの作成／一覧／取得／更新（バージョン管理、`DONE` には PASS 証拠が必要）。 |
| `mazzy_route` | 委譲のための読み取り専用ポリシー事前確認（生成はしない）。 |
| `mazzy_assignment` | 親が証明する実行束ね、完了取り込み、レビュアー証拠。 |
| `mazzy_discussion` | 永続的なタスク議論の読み取り／返信。 |
| `mazzy_control` | ダッシュボードの GO / PAUSE / STOP 要求の claim/complete/fail。 |

**スラッシュコマンド：** `/mazzy`（ステータス + ダッシュボード URL）、`/mazzy-url`
（トークン付きアクセス URL）、`/mazzy-server`（start/stop/status）、`/mazzy-menu`
（`Ctrl+Alt+M`）、`/mazzy-init`、`/mazzy-doctor`、`/mazzy-registry`、`/mazzy-clean`。

## インストール

**要件**

| コンポーネント | バージョン |
|---|---|
| Node.js | `>= 22.19.0` |
| `@earendil-works/pi-coding-agent` | `0.84.2` |
| `@earendil-works/pi-ai` | `0.84.2` |
| `@earendil-works/pi-tui` | `0.84.2` |

**npm からインストール：**

```bash
pi install npm:@mazurovn/mazzy-command-center
# その後、拡張を検出させるために Pi を再起動します。
```

**GitHub からインストール：**

```bash
pi install git:github.com/mazurovn/Mazzy-Command-Center
```

**検証：**

```bash
npm run typecheck
npm test
```

Pi セッションで `/mazzy` を実行してステータスとダッシュボード URL を表示するか、
`/mazzy-url` で認証済みアクセス URL を表示します（トークンはログに書き込まれません）。

## セキュリティと制限

これは**認証済みのローカルパイロット**であり、本番環境のセキュリティ保証として読むべき
ではありません。

- 1 台のマシン、1 人の信頼できるユーザー、親／子プロセス境界。
- マルチユーザー認可**ではなく**、テナント分離**ではなく**、リモート ID **ではなく**、
  分散書き込みリース**ではありません**。
- ダッシュボード操作、送信された制御要求、親の確認は、実行や検証の証拠**ではありません**。

セキュリティ上の懸念は公開 issue ではなく、プライベートなチャネルで報告してください。
